Bundled subtitle fonts
======================

These font files are distributed under the SIL Open Font License (OFL):

- Amiri-Regular.ttf
- Almarai-Regular.ttf
- NotoKufiArabic-Regular.ttf
- Montserrat-Regular.ttf
- Roboto-Regular.ttf
- OpenSans-Regular.ttf
- Cinema-Regular.ttf

Cinema-Regular.ttf is the Cinzel Regular display face used as the
redistributable cinema-style option. The files are bundled locally so
subtitle rendering works offline in both the preview and the MediaCodec
export pipeline.
